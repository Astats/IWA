Checklist from [TEST_PLAN §8.2](../../TEST_PLAN.md#82-m3--cloud-backup). Fill in one table per provider.

## Setup (🧑 HUMAN, see BUILD_PLAN 3.2–3.4)

Copy `apps/web/.env.example` to `apps/web/.env.local` and fill in:

| Variable                | Where it comes from                                                                                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VITE_MS_CLIENT_ID`     | Microsoft Entra ID app registration, platform **SPA**, redirect URI `http://localhost:5173/auth/callback/microsoft`, delegated permission `Files.ReadWrite.AppFolder` only.         |
| `VITE_GOOGLE_CLIENT_ID` | Google Cloud OAuth client, type **Web application**, authorized JavaScript origin `http://localhost:5173`, scope `https://www.googleapis.com/auth/drive.appdata` only.              |
| `VITE_DROPBOX_APP_KEY`  | Dropbox app with **App folder** access, redirect URI `http://localhost:5173/auth/callback/dropbox`, permissions `files.metadata.read`, `files.content.read`, `files.content.write`. |

Then run `pnpm dev` and open `http://localhost:5173`. Use test accounts, not personal ones.
